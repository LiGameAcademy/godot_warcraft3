# 能力系统首轮接入：手动测试

本轮范围：能力系统子模块启用，牧师治疗术 Ahea 和生命药水 phea 共用 `Wc3HealEffect`，生命仍只保存在原有 UnitLife。技能前摇、自动施法、法力消耗及道具冷却沿用现有规则。

## 准备

1. 在 Godot 打开 `game/scenes/game_main.tscn` 并按 F6，等待地图加载完成。
2. 选中己方大法师，F4 打开 GM 面板，点击“生成测试道具”，关闭面板后拾取至少两瓶生命药水。
3. 找到己方牧师（开发配置已有牧师；没有时通过正常生产获得）。测试药水时先把牧师移远，避免自动治疗干扰血量读数。
4. 药水准备：选英雄，GM 点击“血蓝降至30%”。准确比较时暂停观察自然回血产生的小幅变化，或以自动测试的精确数值为准。

观察：治疗术继续使用原有施法及命中特效；本轮没有补齐道具全套模型、图标、音效和拾取反馈，也没有把所有能力改成插件行为树。

反馈请提供编号、操作、实际结果，以及 Godot 错误面板第一条错误。例如：`GAS-07：药水冷却时，牧师治疗也提示冷却。`

## 自动测试入口

- `tests/unit/selftest_gas_healing.tscn`：实际治疗术/药水效果、扣费、满血和目标规则。
- `tests/unit/selftest_item_system.tscn`：原有道具 57 项检查。
- `tests/integration/selftest_items_game.tscn`：真实地图输入、使用、丢弃及祭坛复活。
- 插件独立测试：`addons/godot_ability_system/tests/run_contracts.py`，无需游戏资产。
