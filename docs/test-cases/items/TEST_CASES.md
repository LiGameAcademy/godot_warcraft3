# 道具系统手动测试清单

适用：道具第一版，2026-09-13。请运行 `game/scenes/game_main.tscn`（在 Godot 中选中该场景后按 F6），不要运行默认地图编辑器入口。

## 准备（约 1 分钟）

1. 等待地图加载遮罩完全消失，选中己方大法师。当前开发配置会在主城旁生成大法师；若关闭了开发刷英雄选项，可从祭坛训练英雄。
2. 右侧命令区上方应出现“英雄背包”，共六格。取消选择或选普通农民后隐藏。
3. 按 **F4** 或 **反引号 `** 打开 GM 面板。选中英雄后点“生成测试道具”：英雄附近生成 7 件，包含生命药水×3、魔法药水×2、守护指环×2。
4. 关闭 GM 面板后操作地面物品。为了看清道具，可在 GM 中关闭地面栅格和 Pathing 色块；这些开关不影响道具规则。

背包操作：**左键使用，右键丢弃，按住 Shift 依次左键点两个格子交换位置。** 地面道具用右键拾取。数字仅是槽位编号，本版尚未设置数字快捷键。

## P0：建议全部检查

| 通过 | 编号 | 操作 | 应看到的结果 |
|---|---|---|---|
| [ ] | I-01 | 选英雄，右键近处道具 | 道具进入背包，地面只消失这一件；槽位出现图标和次数/装备文字 |
| [ ] | I-02 | 先把英雄移动远一些，再右键道具 | 英雄走近后才拾取，不会隔空获得 |
| [ ] | I-03 | 走向道具途中按 S，或右键其他地面 | 原拾取被取消；英雄不会过一会儿突然获得旧目标道具 |
| [ ] | I-04 | 捡满六格，再尝试第七件 | 显示满包/需空位提示，第七件仍留在地面；原有六件不变 |
| [ ] | I-05 | 右键背包中的一件，再右键地上对应道具 | 丢弃后空出一格，重新拾取后恢复；不会复制或丢失 |
| [ ] | I-06 | Shift 依次点两个格子；也试一个空格 | 两格内容交换；次数与冷却跟随道具，不跟随槽位 |
| [ ] | I-07 | GM 点“血蓝降至30%”，关闭 GM，左键生命药水 | 生命增加最多 250，不超过上限；消耗一瓶；魔法不被此药水改变 |
| [ ] | I-08 | 继续左键魔法药水 | 魔法增加最多 150，不超过上限；消耗一瓶；生命药水冷却不阻止魔法药水 |
| [ ] | I-09 | 背包准备两瓶生命药水，用第一瓶后立即点第二瓶 | 同组 20 秒冷却；第二瓶不消耗。冷却倒计时结束且生命未满时才可再用 |
| [ ] | I-10 | 先回血到满（可分几次测试），再点一瓶生命药水；满蓝时同理 | 明确提示已满，不扣次数、不启动新冷却 |
| [ ] | I-11 | 装备一枚守护指环，再装备第二枚 | 护甲信息分别增加 2、再增加 2。被动装备无需点击使用 |
| [ ] | I-12 | 丢弃其中一枚指环 | 护甲只减 2；另一枚仍生效。重新拾取又加回 2 |
| [ ] | I-13 | 选农民右键道具；再选敌方/中立单位 | 不会给普通单位新增背包，也不能通过观察敌方背包使用其道具 |
| [ ] | I-14 | GM 点“道具掉落测试怪”，关闭 GM，攻击并击杀测试食人魔 | 测试怪只有 20 生命，死亡后应出现一瓶生命药水和一枚指环；尸体后续消失不会再掉一次 |
| [ ] | I-15 | 背包留几件道具并记下槽位；准备祭坛后 GM 点“英雄阵亡测试” | 英雄阵亡，背包界面隐藏；本次三种测试物品不会自动掉到地上 |
| [ ] | I-16 | 选祭坛，支付复活费用并等待完成 | 英雄恢复原槽位、道具类型与剩余次数；装备加成只应用一次 |
| [ ] | I-17 | 英雄再次阵亡；开始复活后取消队列，然后重新复活 | 道具仍能正常恢复，取消复活不丢道具，也不复制一套 |

注意：英雄复活使用项目现有费用和时间，低等级英雄可能需要等待约 150 秒。测试道具按钮不会免费建造祭坛，也不会跳过复活流程。

## P1：边界与回归

- [ ] I-18：两个己方英雄分别右键同一件物品，最终只有一个获得，另一位的拾取命令结束。
- [ ] I-19：使用第一瓶药水触发共享冷却后，把第二瓶丢掉，立即捡回；冷却不能清零。若有第二英雄，再验证转交也保留冷却。
- [ ] I-20：拾取途中英雄死亡，地面物品应保留，不能进入阵亡英雄的背包。
- [ ] I-21：对不可达位置的道具下令，应结束或提示无法到达，不应卡住后续移动与攻击命令。
- [ ] I-22：清理 Echo Isles 原有带掉落配置的野怪，确认真实生成随机道具；具体品种每次可以不同。
- [ ] I-23：随机得到首版未支持效果的道具，提示中应写“效果未实现”；可携带/丢弃，但点击不能扣次数或伪装生效。
- [ ] I-24：背包打开时仍能使用移动、停止、英雄技能和命令卡；点击背包不会误点地面或命令卡。调整窗口大小后背包不压住命令区。
- [ ] I-25：英雄处于眩晕时点击药水，应拒绝使用且不消耗。
- [ ] I-26：完成采矿、伐木、建造、训兵和一次正常战斗，确认原有玩法没有明显回退。
- [ ] I-27：停止游戏后重新运行，上一局地面道具和背包不应残留；需重新生成测试道具。

## 本版范围

- 已支持：英雄六格背包、地图预置英雄背包数据、拾取/丢弃/换槽、单效果生命恢复、魔法恢复与护甲加成、共享冷却、死亡/复活保存、地图掉落组和随机类别/等级。
- 重点测试物品：`phea`（生命药水）、`pman`（魔法药水）、`rde1`（守护指环 +2）。数值读本地导出的 SLK。
- 未加入：商店买卖、回城卷轴、全物品效果、拾取即生效 PowerUp、道具被攻击摧毁、拖拽投递和跨游戏进程存档。这些物品的未支持效果会明确提示。
- 冷却使用本次运行的时间截止值，转交和死亡不会刷新；当前保存用于同一局内复活，不是磁盘存档接口。
- 地面优先复用已有转换模型和材质处理；缺少可用模型时显示金色小箱子。道具名称悬浮显示。

## 问题反馈格式

请记录：测试编号、具体操作、期望结果、实际结果，以及错误面板中的第一条错误。有截图或短视频也可附上。优先反馈 P0 中无法完成的步骤。

示例：`I-09：背包有两瓶生命药水，用完第一瓶后第二瓶仍可立即使用；预期应有20秒冷却。`
