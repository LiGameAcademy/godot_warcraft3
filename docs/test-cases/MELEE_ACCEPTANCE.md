# 人族对战闭环验收

对应 [长期验收 M1](../roadmap/ACCEPTANCE.md)。本页是执行规程，实际通过情况见 [验收进展](../roadmap/ACCEPTANCE_PROGRESS.md)。

## 自动经营远征

入口：`res://tests/integration/selftest_opponent_campaign.tscn`。从项目根目录运行 Godot console 版：

```powershell
& $env:GODOT --headless --path . --log-file tmp/opponent-campaign.log res://tests/integration/selftest_opponent_campaign.tscn
```

先将 `GODOT` 设置为本机 Godot 可执行文件路径，并确保项目所需地图与转换资源已准备。使用外层运行器时，超时至少允许地图初始化 180 秒、战斗观察 900 秒及清理余量。运行器观察窗口到期但进程尚在运行时，应继续读取同一进程，不能当作测试失败或重新启动。

固定条件：两个人族出生位；电脑拥有正常主城与五名工人、正常初始资源；关闭调试英雄/牧师；不额外生成军队、不补资源、不加速、不直接替电脑下作战命令。另一方保持空闲，电脑战略观察当前使用开发期全图敌情。因此它验证基础自动闭环，不验证公平迷雾 AI 或双方主动对抗。

| 编号 | 必须看到的结果 |
|---|---|
| M1-AI-01 | 地图完成初始化，两方主城确实存在 |
| M1-AI-02 | 正常经营建成兵营与祭坛 |
| M1-AI-03 | 正常付费训练出英雄与步兵 |
| M1-AI-04 | 自产军队自行离开基地超过 2000 魔兽坐标单位 |
| M1-AI-05 | 敌方主城扣血，伤害事件确认攻击者属于电脑且为自产大法师/步兵 |
| M1-AI-06 | 同一伤害事件链确认电脑军队造成主城致命伤害 |

脚本现扩展为 11 项：保留原有八项，并要求同一自然对局由会话自动判电脑获胜、本地显示失败结算、Director 与电脑经营/军队节点停止处理。输出 `PASS (11 checks)` 且退出码为 0 才算扩展剧本通过；历史八项通过不能替代新增结算检查。主城只受伤、军队到达敌方基地、AI 显示 ATTACK 均不足以替代摧毁断言。它也不证明全部 M1 已通过。

每 30 秒记录现实时间 `wall_s`、累计处理帧时间 `sim_s`、资源、人口、单位与战术状态；首次有效伤害和致命伤害另行记录时间。`sim_s` 是该场景累计 `_process(delta)` 的观测量，不是确定性模拟时钟或性能达标证明。观察上限按现实时间计算；延长观察窗口必须明确记录，不能据此宣称通过原有较短时限。

失败时保留完整日志、最终生命、累计有效伤害及退出码。依次区分生产未完成、行军/索敌问题、战斗减员、攻击未命中、进程外层超时。渲染错误另行登记，未测量前不将战斗超时归因于渲染。

## 结算与完整对局待验收

`selftest_melee_victory.tscn` 验证团队所有建筑清场规则；`selftest_match_session.tscn` 验证会话结果锁定与一次性通知。二者是逻辑专项，不能替代以下实际场景：

- 主城被毁但仍有农场或未完工工地时继续对局；盟友有建筑时团队仍未判负。
- 最后一栋建筑被真实伤害摧毁后，会话产生唯一结局，界面显示获胜/失败队伍。
- 结算后停止对战模拟与新游戏命令，菜单仍可操作；退出与重新开局不会沿用上一局结果。
- 从正常开局经英雄清野升级、死亡、付费复活、物品使用/出售、科技升级到胜负结算，连续完成三局。

当前双人开局已接通会话与结算层：`selftest_match_end_game.tscn` 通过真实地图、测试伤害与死亡入口验证唯一结局、本地失败显示、对局节点冻结及外层场景继续处理。`selftest_match_result_screen.tscn` 验证胜利/失败/平局文字与退出请求；有渲染设备时保存三种界面截图。

延迟生命周期专项 `selftest_scene_delay.tscn` 验证冻结、恢复和卸载取消；结算集成已扩展到 12 项，包含待执行回调在结算后停止、卸载后销毁。具体回调迁移与验证范围见验收进展。

重开集成入口：`res://tests/integration/selftest_match_end_game.tscn -- --restart`，通过结算按钮真实替换场景，验证资源、胜负与英雄阵亡记录隔离；当前 21 项检查。其旧局结算采用显式大伤害夹具，不冒充自然经营完整对局。

附加 `--main-scene` 将对局作为根视口下的活动主场景，验证重开时更新 current_scene、卸载时清空；当前通过 24 项检查。初次存在材质/RID 错误；无窗口加载改为主线程分批处理后，三次独立进程回归均通过且无该类错误，详见验收进展。该短夹具仍不能证明长期稳定性。

自然经营到同场结算已有 `PASS (11 checks)`，火球材质修复后的完整复验见 `tmp/natural-material-fixed-output.log`：未出现空材质错误或泄漏报告，仍有攻击动画警告。该次独立运行不能替代连续三局或长期稳定性。

仍待验收：三局连续完成、英雄自然成长/复活与物品科技完整剧本、重开稳定性。当前提供退出和重新开始按钮，未提供战绩统计；双人开局按双方各自成队，尚未接入地图/房间队伍配置。当前十一项自动断言不能替代完整 M1 门槛。
