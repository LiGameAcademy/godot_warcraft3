# 法律与资产合规说明

本项目（`godot_warcraft3`）是使用 Godot 4.6 进行的《魔兽争霸3》玩法复刻实验。仓库**不包含**、也**不会分发**暴雪娱乐（Blizzard Entertainment）的游戏资产。

## 你需要自备的内容

- 参与开发或运行本项目前，你必须拥有**合法获得**的经典《魔兽争霸3》客户端（含 `War3.mpq` 等 MPQ 归档的版本）。
- 资产仅允许从**你本机已安装的客户端**解包到本地缓存目录（默认 `.cache/`），供开发或个人游玩使用。

## 本仓库可以包含什么

- 引擎逻辑、GDScript、工具源码（如 `tools/mpq-extract`）
- 文档、占位资源（如默认 `icon.svg`）
- 与暴雪资产无关的原创内容

## 本仓库禁止包含什么

- 任何 `.mpq` / `.MPQ` 文件
- 从 MPQ 解包出的模型、贴图、音效、地图、UI 等二进制或文本资产
- `.cache/` 下的解包输出与 `manifest.json`
- 指向他人非法分发包的下载链接

## 工具与资产分离

- **工具**（Node 解包脚本、未来的 GDExtension 等）可以提交到 Git。
- **资产**始终留在开发者/玩家本机，由工具从正版安装目录生成缓存。
- 请勿将解包结果提交、打包进发行物，或上传到公开网盘/远端仓库。

## 玩家端（规划）

未来正式发布时，玩家需在首次运行时指定本机经典客户端路径；游戏通过内嵌原生库（计划为 StormLib + GDExtension）解包到用户缓存（如 `user://wc3_cache/`），语义与开发用 `.cache` 清单一致。同样**不会**随安装包附带暴雪资产。

## Mod

项目逻辑通过逻辑路径引用资产，后续可支持用同路径文件替换缓存内容的 mod。Mod 作者仍须自行确保其素材的合法授权；本项目不对第三方 mod 内容负责。
