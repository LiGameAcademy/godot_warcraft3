# 编辑器实时小地图修复（2026-09-13）

- 无预渲染图时，即使勾选游戏小地图，也继续实时刷新；是否使用磁盘图片由实际加载结果决定。
- 实时 UI 直接显示原始宽高的光栅图，不预先填充成正方形。TextureRect 的实际绘制区成为图标、相机框与点击的共同坐标基准。导出 PNG 仍为 256 方形，不改已有导出契约。
- 相机框采用 40 度等效视野（导航示意，不是严格可见性判定）；近水平射线过远时使用稳定回退。按四条地图边界裁剪多边形，避免逐角钳制造成错误边缘，以及线条越出窗口。
- 图标从当前文档单位生成：ngol 金矿、sloc 起始点、nbmm_icon 或中立建筑、owner=12 的非建筑野怪。使用可用的原版金矿/中立建筑图标；野怪使用橙色圆点，256 WC3 单位内合并。该聚合只表达位置邻近，不声称还原原作营地分组或难度。
- 树木模型路径含 tree 的装饰物生成轻量树林遮罩，不改变地形底图。此识别是当前原版资产命名启发式，不保证所有自定义模型。
- 增删、移动、属性修改、撤销重做通过命令回调更新标记/树林；空单位列表不会重新显示已删除的磁盘标记。

验证：selftest_editor_minimap.tscn 使用 D3D12 窗口，LT 12 金矿、5 中立建筑、92 野怪合并为 46 标记，检查裁剪、矩形地图点击/留白、预渲染缺失回退、空标记列表；截图 tmp/editor-minimap-fixed.png。selftest_minimap_dirty、selftest_minimap_raster、selftest_minimap_building_icons 通过。测试环境仍报告证书读取错误。

实时底图仍采用原版纹理代表色与地形光栅，并非完整三维俯视渲染；颜色和细节不会与预渲染图片完全相同。
