# 国际化（I18N）

> 编辑器多语言门面：CSV 为主 + 经典客户端 `WESTRING_*` 覆盖。
>
> 实现：[`editor/ui/editor_i18n.gd`](../../../editor/ui/editor_i18n.gd)（Autoload `EditorI18n`）
> CSV：[`editor/locale/editor_strings.csv`](../../../editor/locale/editor_strings.csv)
> 翻译资源：`editor/locale/editor_strings.{en,zh_CN}.translation`

## 1. 总览

```text
编辑器字符串查找
  │
  ├─ 1. CSV 表（editor_strings.csv）
  │     → _tables[locale][key]
  │
  ├─ 2. 经典客户端 WESTRING 覆盖（_mpq）
  │     → 同 AssetProvider 路径：assets/asset-converted/UI/ → .cache/wc3-assets/UI/
  │
  └─ 3. 兜底：返回 key 本身
```

**支持 locale**：`zh_CN`（默认）/ `en`。

## 2. 配置

| ProjectSettings 键 | 含义 | 默认 |
|--------------------|------|------|
| `locale/translations` | Godot 翻译资源 | `editor_strings.en.translation` / `editor_strings.zh_CN.translation` |
| `locale/locale_filter_mode` | `0` = 接受所有 locale | `0` |
| `locale/fallbacks` | 回退 | `["en"]` |

> `project.godot` 已配：
> ```ini
> [internationalization]
> locale/translations=PackedStringArray("res://editor/locale/editor_strings.en.translation", "res://editor/locale/editor_strings.zh_CN.translation")
> locale/locale_filter_mode=0
> locale/fallbacks=["en"]
> ```

## 3. API

| 字段 / 方法 | 含义 |
|-------------|------|
| `get_locale() -> String` | 当前 locale |
| `set_locale(locale: String, notify: bool = true)` | 切换 locale（自动写 `user://editor_locale.cfg`） |
| `t(key: String, args: Array = []) -> String` | 主查询；`%s %d` 等格式化 |
| `label(key: String) -> String` | 标签套娃（`EDITOR_NEWMAP_LABEL_COLON: "%s:" % key`） |
| `tile_display_name(tiles, tile_id) -> String` | 地表贴图显示名（含不可建造后缀） |
| `strip_accel(s: String) -> String` | 去 Windows/WE 加速键标记：`&F`→ 隐藏，`&&`→ 字面 `&` |

**信号**：

```gdscript
signal locale_changed(locale: String)
```

UI（菜单/工具栏）监听此信号刷新 `text`。

## 4. CSV 格式

[`editor/locale/editor_strings.csv`](../../../editor/locale/editor_strings.csv) 三列：

| 列 | 含义 |
|----|------|
| `key` | 字符串 ID（`EDITOR_*` / `WESTRING_*`） |
| `zh_CN` | 中文 |
| `en` | 英文 |

例：

```csv
key,zh_CN,en
EDITOR_FILE,文件,File
EDITOR_NEW,新建(&N),&New
WESTRING_TILE_GREEN,绿草地,Green Grass
```

**约定**：
- `EDITOR_*` —— 编辑器自身字符串
- `WESTRING_*` —— 经典客户端字符串（可被 `WorldEditStrings` 覆盖）
- 加速键 `&` 后跟字母 —— Windows 风格（`strip_accel` 处理）
- 转义 `&&` → 字面 `&`

## 5. 加新字符串流程

1. **打开** `editor/locale/editor_strings.csv`
2. **加一行**（key / zh_CN / en 三列）
3. **保存** —— Godot 编辑器会自动重生成 `.translation` 文件
4. **代码** 用 `EditorI18n.t("KEY_NAME")` 查询
5. **测试** —— 切换 locale 确认两语言都正常

或**仅在脚本中用**：

```gdscript
# 不经 CSV
TranslationServer.translate("MY_KEY")
```

## 6. 经典客户端覆盖

`EditorI18n._ready` 调 `_load_mpq_overlay()`，按 `AssetProvider` 路径解析：

```
assets/asset-converted/UI/WorldEditStrings.txt   (优先)
.cache/wc3-assets/UI/WorldEditStrings.txt       (回退)
```

同步工具：[`tools/sync-editor-assets.mjs`](../../../tools/sync-editor-assets.mjs)：

```bash
node tools/sync-editor-assets.mjs
# → assets/asset-converted/UI/WorldEditData.txt 等
```

`WorldEditStrings.txt` 是经典 WE 的字符串表，编辑器在 `zh_CN` 下用其中的中文覆盖（更地道）。

## 7. UI 控件翻译模式

**菜单**（[`menu_bar.gd`](../../../editor/ui/menu_bar.gd)）：

```gdscript
# item text = 翻译 key（而非本地化字符串）
menu.set_item_text(idx, EditorI18n.t("EDITOR_FILE_NEW"))

func _on_locale_changed(_locale: String) -> void:
    # 重设所有 item text
    for i in range(menu.item_count):
        var key: String = menu.get_item_text(i)  # 此时已是 key（已替换过）
        ...
```

**工具栏**（[`toolbar.gd`](../../../editor/ui/toolbar.gd)）：用 `tooltip_text` / `text` 同理。

**Tool Palette 浮窗**（[`tool_palette_window.gd`](../../../editor/ui/tool_palette_window.gd)）：地表贴图显示名走 `tile_display_name()`。

**对话框**（[`new_map_dialog.gd`](../../../editor/ui/new_map_dialog.gd)）：label 用 `label("KEY")`（自动加冒号）。

## 8. 持久化

`EditorI18n` 在切换 locale 时自动写：

```
user://editor_locale.cfg
```

下次启动读回，**无需重选**。

```gdscript
# CONFIG_PATH
const CONFIG_PATH := "user://editor_locale.cfg"
```

## 9. 何时查哪里

| 想改什么 | 去哪 |
|----------|------|
| 加新字符串 | `editor/locale/editor_strings.csv` |
| 改加速键 / 加速键解析 | `editor/ui/editor_i18n.gd`（`strip_accel`） |
| 改默认 locale | `editor/ui/editor_i18n.gd`（`_detect_default_locale`） |
| 改世界编辑器字符串 | `assets/asset-converted/UI/WorldEditStrings.txt` |
| 同步 WE 资产 | [`tools/sync-editor-assets.mjs`](../../../tools/sync-editor-assets.mjs) |
| 改 ProjectSettings 翻译 | `project.godot` `[internationalization]` |
