# 天外机群、工程传统与半身人起源

> 版本：0.2 · 日期：2026-09-14  
> 状态：世界背景提案。非血肉生命可以承载灵魂、机械文明曾经存在、其遗迹影响地精与矮人为推荐方向；机械文明正式名称、深层存在真相、矮人确切起源和半身人寿命数值继续留白。  
> 配套：[世界底层规则](COSMOLOGY_AND_MAGIC.md) · [世界观与三大联盟](WORLD_AND_ALLIANCES.md) · [地理与魔力生态](GEOGRAPHY_AND_MAGIC.md)。

## 1. 本轮结论

1. 本世界允许硅质、晶体与金属构成的非血肉生命，因为灵魂来自魔力在复杂物质结构中的聚合，不由碳基血肉垄断。
2. 传说中的机械族确实留下过遍布地下的城市、矿井和自动设施，但在当前时代已经不构成公开活动的大型文明，也不作为第四个首发可玩阵营。
3. 它们很可能由天外种子、探测器或流亡舰体带来；作者层面确认存在天外成分，世界内人物尚不能证明它们来自哪颗星或为何抵达。
4. 地精最接近遗迹所在的荒漠，掌握了最多逆向知识；这解释其狂野工程传统，却不使所有地精都成为工程师。
5. 矮人文明与机械遗产有深层关系，但暂不锁定为“机械族直接创造矮人”。推荐保留多个互相竞争的起源模型。
6. 半身人是与精灵拥有远古共同祖先的湖盆族群，外貌向人类趋同来自长期环境适应，不是矮人或人类的缩小版本。
7. 半身人的社会优势放在观察、教育、信息网络、精密仪器和魔法研究上；“聪明”由制度、训练和城市网络表达，不写成每个个体的血统天赋。

## 2. 非血肉生命如何符合底层规律

物质是魔力的承载结构，灵魂是魔力在足够复杂、能够维持自我连续性的物质系统中发生的涌现。血肉细胞是一种载体，硅质晶格、金属回路和魔力晶体也可以成为载体。

| 生命问题 | 血肉生命 | 晶格生命 |
|---|---|---|
| 身体材料 | 水、盐、脂肪、蛋白、骨和其他有机物 | 硅质晶体、金属、陶质绝缘层、导魔矿物与少量流体 |
| 能量来源 | 食物、呼吸、环境魔力及体内转化 | 热差、电荷、环境魔力和富魔矿物中的可释放势能 |
| 灵魂依托 | 神经、器官、生命回路和持续代谢 | 具有反馈能力的晶格、回路、共鸣腔和持续能流 |
| 生长与修复 | 摄取物质后由身体自行生长 | 开采、提纯和装配新材料，再由核心晶格重新组织 |
| 繁衍 | 生物生殖与发育 | 分出晶核、共同铸造新核心，或让新的复杂晶格在共鸣场中觉醒 |
| 死亡 | 生命回路不可逆崩解，灵魂失去稳定容器 | 核心连续性断裂、能流停止或记忆晶格无法维持整体自我 |

矿物对机械族具有双重意义：普通矿物是身体材料，富含魔力的矿物又是能量与记忆介质。它们迷恋采矿不是无意义的程序错误，而是粮食、繁衍、医疗、建筑和能源都依赖同一套地质资源。

残留机械能够重新启动，不代表原本的生命已经复活。若只有旧程序重复运行，它是自动设施；若原有连续灵魂仍被核心维持，才可能是幸存者；若外来灵魂进入空壳，则属于灵魂移植或特殊亡灵问题。

## 3. 天外来客与玻陨荒原

主大陆内陆存在一片远离现今城市的高魔力荒漠，工作名为**玻陨荒原**。地表分布大片熔融玻璃、方向异常的磁铁矿、缺少本地地质来源的合金碎片，以及向地下延伸的规则竖井。

作者层面只锁定以下事实：

- 某种具有非本地材料的天外结构在远古坠落或降落于此。
- 坠落物携带能够自我复制、调整身体并形成独立意志的晶格生命种子。
- 后来的地下机械文明与这些种子存在直接延续关系。
- 它们不是创造世界的神，也不是所有魔法的来源。

世界内存在多种解释：析光学者认为它是其他行星文明的播种体；矮人祭史称其为从天炉落下的“初铸者”；地精商会把它称作“第一批没有账本的旅客”；精灵长庭则怀疑它是穿越无形域而非星海抵达。现阶段不裁定航行方式。

## 4. 晶格群：不是单一蜂巢

机械文明的学术工作名为**晶格群**，不作为最终自称。它们可以通过矿脉、共鸣塔和地下导体同步记忆片段、地图和危险警报，形成类似分布式档案的“群响”。

群响不抹除个体意志。每个晶格生命拥有连续核心、局部记忆和选择能力，可以拒绝同步、隐瞒发现或离开网络。它们的主要政治矛盾可能正是：共享到什么程度仍算合作，从何时开始变成强迫同化。

这种设计保留群体机械文明的陌生感，同时与简单的蜂巢或吸收一切生命的机械军团拉开距离。少数派可能主张把血肉生命转写进晶格，但不能把这种极端派等同于整个文明。

## 5. 地下铸城为何出现

晶格群沿富矿层向地下扩张，建立由竖井、运输环线、熔炼腔、晶核培育室和共鸣塔组成的庞大铸城。地下环境对它们有四项优势：

1. 温度变化较小，便于维持精密晶格。
2. 矿体能够同时提供身体、能源、建筑和记忆介质。
3. 岩层屏蔽地表魔力风暴与天外辐射。
4. 地下导魔矿脉可以承担远距离群响网络。

它们越成功，便越依赖持续开采。旧矿枯竭后，铸城向更深地层钻探；运输和意识网络也逐渐集中到少数高纯度主矿脉。一旦这些主脉同时失效，文明会像失去粮道、道路和语言一样整体崩溃。

## 6. 断响之夜与深层存在

晶格群最终穿透一层长期封闭的高压岩壳，接触到一个横跨地幔热流与深层魔力流的巨大意志。后世称它为**深眠者**，但没有人知道它是古老元素生命、行星自身形成的防御反应、被封印的天使或恶魔，还是由整片矿脉涌现的地质灵魂。

可以确认的事件只有：

- 深层钻探导致大范围共鸣异常、地震与魔力逆流。
- 某种回应沿晶格群赖以通信的主矿脉高速传播。
- 大量核心在同一时期熔毁、静默或互相攻击，后世称为“断响之夜”。
- 数座铸城被岩浆、塌方和主动封门共同埋葬。
- 深眠者此后没有公开出现在地表，但某些深井仍会传出不属于机械设施的低频回应。

晶格群的网络优势成为致命弱点：袭击可以沿群响扩散。不能确认深眠者是有意灭绝它们，还是一次规模悬殊的自卫反应。这个问题保持空白，避免把“挖得太深惊醒远古怪物”写成简单善恶报应。

## 7. 当前时代还剩下什么

机械族覆灭并不意味着所有设施彻底停止：

| 遗产 | 当前状态 | 叙事与玩法用途 |
|---|---|---|
| 静默铸城 | 大部分封闭，少数外层被矮人或地精重新开启 | 地下城、资源争夺、机关环境和历史考察 |
| 自动采掘体 | 按失效指令持续工作，可能把城市和生境判定为矿层覆盖物 | 中立威胁、护送或停机目标，不自动代表机械族复国 |
| 失联个体 | 极少数核心避开断响，可能失忆、休眠或拒绝连接任何网络 | NPC、英雄或道德选择候选，数量不足以形成首发阵营 |
| 共鸣碎片 | 保存地图、感觉或不完整人格，真假难辨 | 任务证据、装备材料和灵魂哲学冲突 |
| 深井封门 | 由机械、矮人、精灵或未知力量分别加固 | 高风险战役地点；开启封门不保证获得宝藏 |
| 天外合金与晶核 | 数量有限且无法稳定复制 | 地精原型机、矮人国宝和析光研究材料，禁止成为无限日常资源 |

首发版本只需表现一处封闭遗迹、一类自动守卫和一件有明确代价的遗物。机械文明的完整历史可以留到战役中逐层揭示。

## 8. 地精为何最接近它们的技术

玻陨荒原位于百泉走廊外侧的盐风盆地深处。地精商站比三大联盟更早形成稳定穿越路线，并通过修井、测向、商队互助和多语言情报积累掌握遗迹入口。

地精没有完整理解晶格群理论。他们擅长把遗物拆成可工作的部件，再用蒸汽、火药、普通金属和魔力电池替代缺失材料。这形成“狂野工程”风格：功能大胆、模块可换、现场维修能力强，但噪声、过热、谱相污染和失控风险明显。

地精工程不能只用于爆炸笑料。它覆盖沙漠车辆、抽水机、义肢、测矿仪、便携通信、医疗器械、自动装卸与遗迹防护。事故很多，是因为他们在材料不足、客户催促和各国封锁下推动原型，并非因为整个族群愚蠢或不负责任。

部分商会垄断遗迹坐标，部分学者要求公开以防止灾难，部分工程师希望唤醒失联机械生命询问原理，另一些地精担心这会再次引来深眠者。地精由此拥有商业以外的学术、伦理和政治冲突。

## 9. 矮人与机械遗产的关系

推荐把联系定为事实，把确切起源保留为谜团：最早的矮人高原城堡确实使用晶格群留下的承重结构、排水系统和熔炼腔；矮人身体对矿尘、重金属与地下魔力的适应也异于多数地表族群，但这不足以单独证明他们由机械族创造。

世界内有三种主要学说：

| 起源学说 | 主张 | 争议 |
|---|---|---|
| 初铸后裔说 | 晶格群在覆灭前尝试为自己制造不依赖群响的血肉容器，矮人是其成功后裔 | 能解释部分古老身体测量与铸城规格相合，却缺少连续化石和完整记录 |
| 避难共生说 | 矮人祖先原本是高原血肉族群，断响灾难时进入铸城，与失联机械个体共同生存并继承技术 | 更符合语言和家族传承，但无法解释某些先于避难年代的矿物适应 |
| 遗迹塑形说 | 矮人本有独立起源，长期生活在铸城环境和高魔力矿区，使身体与文化逐渐适应地下 | 不需要创造者，却难以解释最早矮人为何能安全启动部分设施 |

作者层面暂不选定唯一答案。无论真相为何，现代矮人都是拥有完整自我历史的文明，不是等待原主人回归的工具。他们迷恋采矿与工程来自高原生计、铸城遗产、政治权力和宗教记忆的共同作用。

矮人技术与地精技术形成差异：矮人只采用能够测试、维护并传给下一代工匠的结构；地精愿意让一个不完全理解的遗物先完成任务，再从失败中迭代。双方既互相鄙视，也离不开对方。

## 10. 半身人的远古精灵起源

半身人与精灵拥有远古共同祖先。早在长庭王朝形成以前，一支精灵先民沿西南河谷进入暖湿湖盆，与东南故土长期隔绝。湖盆食物结构、湿热环境、山地交通、较弱但变化频繁的魔力场，以及与早期人类聚落的长期接触，共同推动其身体和生命节律发生改变。

经过远比开门革命更漫长的世代，他们形成较矮小的体型、较接近人类的面部比例和不那么突出的耳形，外观看起来像精致的小型人类。他们仍保留若干古精灵语言结构、敏锐的魔力感知和对细节的良好辨识能力。是否存在少量远古人类血缘可以留白；人类化外貌首先解释为趋同适应，不必立即引入跨种生殖体系。

半身人的寿命介于人类与长庭精灵之间，具体年数后置。较快的世代更替使他们比长庭更容易更新制度，古精灵遗产又使其重视档案、谱系和魔法教育。这能解释他们既熟悉人类政治节奏，又擅长解读精灵资料。

“机敏、聪明”主要来自湖盆诸邦的制度：

- 小国处于高原、海岸王国、百泉走廊和三河平原之间，必须依靠情报与外交生存。
- 密集灌溉要求准确记录水位、田亩、债务和上下游关系，推动普及算术与文书教育。
- 山路和湖运形成驿站、旅店、船户与商人共同维护的消息网络。
- 体型和精细动作适合操作小型仪器，但职业选择仍由训练、家庭和个人决定。
- 长期处于强邻之间，使伪装、密码、翻译、谈判和反情报成为正式公共职业。

半身人不是性格单纯的田园陪衬，也不是全族间谍。他们拥有农民、渔民、贵族、法师、工匠和士兵；只是湖盆国家最受重视、最有国际影响力的输出是情报人员、测绘师、密码师、魔法仪器师和研究者。

长庭对半身人的态度复杂。部分精灵视他们为失落远亲，另一些坚持他们早已脱离古约；半身人则不接受“回归长庭”的要求，认为共同祖先不能取消几千年的独立历史。析光城更愿意承认他们为平等学术伙伴，因此聚集了大量半身人研究者。

云泽继承危机改变了这种关系。人类沿海王室试图通过婚姻、债务与驻军干预湖盆盟会，长庭则必须放弃祖源宗主权，才换得多数半身人诸邦签署远枝盟约。半身人由此成为精灵联盟的平等政治成员，而不是长庭臣民；少数西部城邦、析光学者和人类城市侨民仍维持不同归属。共同祖先解释了双方为何能够重新谈判，现实利益与制度保障才解释他们为什么结盟。

## 11. 工程与科研生态

| 文明或机构 | 主要工程传统 | 优势 | 代价与盲点 |
|---|---|---|---|
| 矮人高原诸堡 | 重型矿业、冶金、火器、堡垒、水力与可维护机械 | 稳定、耐久、标准严格 | 迭代缓慢、工艺行会保密、拒绝尚未理解的方案 |
| 地精商会与荒原工坊 | 遗迹逆向、移动机械、义肢、自动装置和现场改装 | 大胆、模块化、能在材料不足时工作 | 故障率、遗物依赖、商业压力与危险知识垄断 |
| 半身人湖盆诸邦 | 精密仪器、测绘、密码、通信、炼金和魔力检测 | 小型化、信息准确、跨机构协作 | 依赖复杂供应链，情报机构可能侵蚀私人生活 |
| 析光城邦 | 魔法理论、结界、空间、人工元素与魔导器械 | 能把不同技术统一成可教学体系 | 高能事故、伦理争议、粮食和材料依赖 |
| 人类沿海诸邦 | 船舶、城防、工坊量产、道路与行政标准 | 扩大生产规模并组织跨族项目 | 官僚和军方可能把技术优先用于扩张 |
| 兽人诸部 | 车辆、鞍具、复合材料、野战架设和极端环境维修 | 轻便、可靠、适合迁徙与快速部署 | 不适合长期重型设施，知识容易依赖特定工匠谱系 |
| 精灵长庭 | 水利、生境工程、培育材料、长期结界和生命修复 | 低耗、耐久、能与生态共同运转 | 建设周期长，对深层魔法和快速试验过于谨慎 |

任何一方都不垄断“科技”。同一台战争机器可以包含矮人炮管、地精遗迹核心、半身人瞄具、析光结界和人类量产底盘；它们也会围绕专利、责任、维修权和事故归属争吵。

## 12. 对首发内容的约束

- 机械文明暂不成为第四个可玩阵营，也不突然发动全球入侵。
- 首个机械遗迹只展示一种核心视觉语法：深色陶金属、大块晶格、重复几何和断续共鸣光，不复制博格式植入物与黑绿配色。
- 地精首发单位若使用遗迹技术，必须有可读的过热、装填、故障风险或资源代价，不能以“疯狂”解释无限强度。
- 矮人单位保持可靠重工定位；与地精的差异通过结构、维护方式和战斗节奏表现。
- 半身人主要作为精灵联盟的侦察、情报、魔法检测或精密支援角色进入，不把潜行和偷窃设为全族特性；人类地图中仍可出现旧盟城与侨民，但常规对战不跨阵营复制同一套单位。
- 深眠者只留下声音、地震、封门和失真记录；在其性质未明确前不制作完整怪物形象。
