## 1. 编年史首先区分三种真相

| 层次 | 当前处理 | 示例 |
|---|---|---|
| 作者层硬规则 | 可以约束所有故事，但不要求世界内人物知道 | 物质承载魔力；复杂聚合能够产生灵魂；天使、恶魔、元素和亡灵服从同一底层规律 |
| 世界内可证事实 | 多种独立史料、遗物或可重复现象能够互相印证 | 精灵留下目前已知最早的连续文字；初衡台远早于现存三大联盟；三河公约确实结束了圣城远征时代 |
| 传统解释 | 人们相信并据此行动，却不能由作者替他们证明 | 谁最先觉醒、初衡台由谁建造、世界是否具有道德意志、初约是否来自超越生命的启示 |

编年史不写成一位全知旁白宣布唯一历史。越接近当前时代，日期和基本事件越可靠；越接近创世，文本越像神话、仪式、残片和后世政治声明。

## 2. 最早觉醒者：精灵的史学地位

精灵可以被设置为**目前已知最早留下连续自我记录的智慧生命**。这比作者直接确认“精灵是世界第一个智慧种族”更有价值：

- 长庭档案中的水纹简、记忆木和石刻能形成跨越数千年的文书链。
- 长寿者能够亲自向数代学生复述事件，使精灵历史具有罕见连续性。
- 连续记录也给予长庭定义年代、命名古族和宣布土地古约的权力。
- 一份保存最久的档案仍可能是胜利者档案；删除、重抄、仪式化记忆和精灵自身的政治需要都会改变历史。

“最先觉醒者”因此是通行史学称号，不是已经证明的宇宙事实。至少有三类反证持续存在：静默铸城可能早于最古老精灵文字；三河岩台下存在无法辨认建造者的结构层；兽人长歌包含与精灵古历天象相符、却没有文字记录的远古段落。

## 3. 每个文明都有自己的创生传说

这些传说表达文明如何理解责任，不负责替物理设定作证明。

### 3.1 精灵：《生庭歌》

世界最初是一座没有名字的黑暗庭园。第一束魔力进入石、水和种子后，生命开始记住自己。最早的精灵在三条河相遇之处醒来，听见世界要求他们“让流动继续”。他们修建初庭、记录周期并把守护责任传给后代。

这则神话支持长庭的监护权，也留下危险倾向：如果精灵相信自己是世界最早指定的维护者，就很容易把别族的生活视为需要被管理的后来者。

### 3.2 人类：《持火行记》

最早的人类没有固定故土，只在漫长寒夜中轮流携带一盏会熄灭的火。火不询问血缘，只要求持火者在下一处营地接纳陌生人。第一座人类城不是由同一祖先繁衍而成，而是由互不相识的人共同守住火种。

人类由此强调：古老血统不能垄断真理，任何人都可以通过公开誓言、共同劳动和承担后果进入盟约。这既支撑城市公民和跨族联盟，也可能被扩张者用来宣称自己的制度适用于所有人。

### 3.3 兽人：《苍狼引路歌》

远古天空没有固定星位，先民在无边寒原上失去方向。一支狼群没有服从他们，而是在远处反复出现，引导愿意分享猎物、保护幼崽并遵守水源次序的人越过风雪。抵达三河后，各部在狼群见证下发誓停止复仇。

兽人并不认为自己从人类传统“改宗”而来；行誓传统把更古老的祖誓、狼盟和后来传入的三河文本重新结合。道路上的实际履约比拥有最古老经卷更重要。

### 3.4 半身人：《远枝渡水记》

一支幼枝被洪水带离第一庭园，在陌生湖盆扎根。它没有变回原来的大树，而是生出低矮、繁密、能够抵御暴雨的新枝。半身人据此承认与精灵同源，也拒绝“失落后回归”的说法：离开本身就是一次创造。

### 3.5 矮人：三种初炉说

山堡没有统一创世论。王室祭炉者认为第一批矮人由山心在火与压力中孕育；部分工匠相信祖先是晶格群制造的独立容器；学者则主张血肉先民进入铸城后逐代适应。三种学说分别关系到王权、遗迹所有权和危险机械是否可以继续启动。

### 3.6 地精：《第一账》与无始论

地精商会流传一句带讽刺意味的话：“世界开始于第一笔有人承认的欠账。”严肃的译路学者并不把它当作创世事实，而是认为任何关于开端的说法都必须回答：由谁记录、使用什么尺度、谁从这种记法获益。

部分地精相信宇宙没有可被贸易者确定的“第一天”，只有不断修订的账册。这使他们很少争夺最早觉醒者称号，却成为跨文明年代换算、文书鉴伪和史料流通的重要力量。

## 4. 不直接复制三大一神教，采用“衡约诸传”

犹太教、基督教与伊斯兰教适合提供“共享古老人物与事件、彼此提出竞争解释、又在长期接触中共同塑造自身”的历史结构，不适合分别绑定成精灵、人类和兽人的种族宗教。相关传统并非简单的单向复制链；现代研究也强调它们在相互接触、辩论和重新解释中持续共同形成。[Cambridge University Press：Co-produced Religions](https://www.cambridge.org/core/journals/harvard-theological-review/article/coproduced-religions-judaism-christianity-and-islam/0E3815326972E42D441FD64F598BF3BF)

本世界采用**衡约诸传**作为等价结构。它既包含宇宙解释和仪式，也包含水权、待客、战争限制、葬礼、历法与公共法律，因此不能简单归类为现代意义的宗教或哲学。

共同母题是“初约”：远古某次洪水与魔力失衡期间，不同生命在三河岩台上第一次学会共同操作初衡台，并约定任何一方不得让世界的流动只服务自己。是否真的有超越世界的意志说出这些话，各传统一直没有共识。

### 4.1 精灵的守衡传统

精灵认为初约首先存在于地点、关系和跨世代责任中。后人不能因为没有亲自签字就拒绝维护上游森林、下游水量和记忆设施。祭司、园师、历官与档案家共同解释古约。

优点是能够承担数百年的生态工程；风险是解释权被长庭和旧族垄断，把“替未来负责”变成压制当代居民的理由。

### 4.2 人类的众约传统

人类接触精灵古约后提出：如果初约关系到所有生命，就不能只由最早记录它的人继承。任何族群和个人都能通过公开承诺、互相见证、救济陌生人与共同守城进入众约。

众约诸会建立医院、旅舍、学校、抄写所和护路团，也产生教阶、法庭与军事修会。它能够支持跨族公民制度，同样可能以“向所有人开放”为理由否定地方旧法、发动护约远征。

### 4.3 兽人的行誓传统

兽人认为一份从未在饥饿、迁徙和复仇中接受考验的文本只是安静的符号。誓言必须被反复说出、付出代价并由同行者记住，才成为活的约。听灵者、道路见证人和部族长者共同维护口传，但不形成唯一中央教会。

行誓吸收了人类译本、精灵水权知识、兽人祖誓与狼盟。它宣称自己恢复了初约的行动本义，而不是继承人类教会。其力量是让不同部族迅速建立可信关系；风险是战功领袖把胜利解释为自身履约正确的证明。

### 4.4 地精的译路传统

地精没有创造第四个“正统”。商队译员、历算师和契约见证人把三方文本带过边疆，制定日期换算、度量衡、赎俘价格和朝圣通行证。他们在翻译时不可避免地改变概念，也会为贸易便利选择某种解释。

三方都指责地精“把神圣变成合同”，却又依赖其副本、路线和中立见证。地精因此是衡约诸传的共同塑造者，不是躲在幕后发明或操控三种信仰的秘密群体。

### 4.5 圣经式母题如何转译

可以借鉴经典叙事的结构张力，但不复制人物、神迹、经文或现实族群对应关系：

| 叙事母题 | 本世界的转译 | 留下的争议 |
|---|---|---|
| 创世与伊甸 | 《生庭歌》把世界写成最初庭园，精灵从能够记忆自身的生命中醒来 | 第一庭园是现实地点、三河旧称，还是后世隐喻 |
| 洪水与惩罚 | “大失衡”使早期三河水工崩溃，洪水与魔潮迫使精灵先民东迁 | 灾害是自然循环、工程事故，还是某种意志对独占初衡台的回应 |
| 出走与流散 | 幸存者携带水纹简离开初庭，在东南河网建立长庭；另一些群体继续西迁并成为半身人先民 | 长庭称其为保全古约，反对者称其为抛弃三河居民 |
| 立约与律法 | 初约被整理成水权、待客、葬礼、战争限制和共同维护程序 | 它来自启示、灾后会议，还是后世将多份规则拼成一部古约 |
| 圣所毁坏与回归 | 初庭设施多次被洪水、内战和远征破坏；精灵始终保留维修队、朝圣者与回归主张 | 长期维护是否产生主权，还是只能产生服务义务 |
| 普遍化 | 人类众约传统宣称任何人都能通过公开承诺进入初约，不受精灵谱系和古历限制 | 普遍伦理何时变成否定地方差异的制度扩张 |
| 复兴与校正 | 兽人行誓传统宣称经卷已经被城市权力冻住，必须回到旅途、互助和实际履约 | “恢复原义”是改革、重新创造，还是共主整合诸部的政治工具 |
| 朝圣与圣战 | 三方道路在三河交汇，护路、朝圣保护与军事远征逐渐纠缠 | 真诚信仰、领土利益、债务与个人野心无法被整齐分开 |

这里不设置“天选种族”这一客观事实。精灵可以相信自己首先受托，人类可以相信初约向所有人开放，兽人可以相信只有兑现者才算真正守约；作品只确认这些信念塑造了历史。

## 5. 三河城为何成为世界历史中心

三河城不是行星中心，也不是已证实的创世地点。它成为已知世界的历史中心，有五个可以验证的原因：

1. 三条大河和多条陆路在此汇合，文书、口传、商品和难民不断交换。
2. 初衡台确实能够调节洪水和魔力流，三方都无法忽视其现实作用。
3. 城市包含最深的连续聚居层，却没有一种史料能够独占全部历史。
4. 圣城远征把三方政治、信仰和法律第一次长期卷入同一座城市。
5. 《三河公约》成为外交、通商、朝圣和历法换算的共同依据。

这是一种“史学中心性”：研究任何联盟的历史，最终都会在三河找到该文明留下的档案、墓地、债务、圣区或战争痕迹。世界其他大陆和古老文明仍可存在，不需要围绕三河运转。

## 6. 共同纪年：三河公约纪元

国际史学、外交文本和游戏界面采用**三河公约纪元**，简称**公约纪**。

- 纪元从最终版《三河公约》正式交换誓本之年开始。
- 没有“公约纪零年”：签约前一年写作“公约前1年”，下一年为“公约纪1年”。
- 当前主线暂定为**公约纪327年**。
- 标准写法为“公约纪327年·某月·某日”；月份和一年的精确天数等天文历法定稿后补充。
- 古代事件使用范围和可信度，例如“公约前约4700—4500年，长庭换算，可信度C”。

公约纪不是任何一方的创世历，因此相对容易被接受。它仍有政治性：人类喜欢它纪念成文条约，三河市民喜欢它确认自治，兽人批评签约年遮蔽更早祖誓，精灵则认为把漫长古史压缩为“公约前”是一种短寿文明偏见。

### 6.1 各文明自己的历法

| 历法 | 使用者 | 计时逻辑 | 叙事作用 |
|---|---|---|---|
| 长轮历 | 长庭、雨历诸庭及精灵学宫 | 以星象、洪水、花期和魔潮构成多层循环；用王朝校订号区分版本 | 能精确描述周期，却会因改历而改变旧事件的政治解释 |
| 王历与众约节历 | 人类诸邦和众约诸会 | 王室用在位年，教会与城市用共同节期；外交时换算为公约纪 | 同一场战争可能有多个“第七年”，推动档案争议 |
| 迁季纪 | 兽人诸部 | 以冬营、异常天候和大会为年名，重要誓约用事件前后定位 | 适合口传和迁徙记忆，不等于缺乏历史精度 |
| 炉次 | 矮人山堡 | 以主炉连续点燃、停炉和重铸划分时代 | 工程记录极准，不同山堡之间换算困难 |
| 通路历 | 地精商会 | 为利息、交货和远途航行建立连续数字表，并保存各历法对照 | 成为国际换算工具，也让商会能通过历表控制信息 |

世界文本首次出现本地日期时，可以并列公约纪换算；后续只显示剧情最需要的一种。玩家永远不需要现场计算五套历法。

## 7. 首版里程碑编年史

日期越早，误差和争议越大。下表中的公约前年份只是三河史家换算，不代表古人使用同一套历法。

| 公约纪换算 | 里程碑 | 可以确认的部分 | 继续留白的部分 |
|---|---|---|---|
| 无法纪年 | **虚空分化** | 只作为当前最有解释力的宇宙模型 | 是否发生过一次创世、是否存在创世意志 |
| 公约前4800年前后 | **最古水纹记录** | 精灵留下目前最早的连续文字与天象记录 | 它是否记录精灵初醒，还是更古老口传的重写 |
| 公约前4500—4300年 | **初衡层形成** | 三河岩台出现早期水工与魔力调节结构 | 建造者、用途，以及是否早于精灵到来 |
| 公约前4250年前后 | **大失衡与东行** | 三河早期设施崩溃，洪水和魔潮造成迁徙；部分精灵档案在东南重新出现 | 灾害起因、死亡规模，以及长庭是否夸大自身对古约的继承 |
| 公约前3900年前后 | **长庭定历** | 多个精灵城市接受一套可换算的历法和水权档案 | 这是自愿联盟、征服结果还是后世王朝神话 |
| 公约前3500—3200年 | **远枝西迁** | 半身人先民进入西南湖盆并逐渐与东南故土隔绝 | 迁徙原因、沿途人群和是否存在多次迁徙 |
| 公约前2900年前后 | **人类持火城兴起** | 西南河谷出现城墙、共同粮仓和跨家族公民誓约 | 人类是否源自一处，以及《持火行记》的最早层次 |
| 公约前2500—2200年 | **道路传译时代** | 地精商路开始系统换算精灵历法、人类城约与北方年歌 | 哪些概念在翻译中被创造，而非忠实传递 |
| 公约前2100—1700年 | **衡约三传成形** | 守衡、众约和行誓已经能被辨认为不同传统 | 是否存在一位共同导师、一次启示或多个独立源头 |
| 公约前900—700年 | **断响之夜** | 晶格群地下网络崩溃，大量铸城同时失联 | 深眠者是否主动攻击、矮人与事故的真实关系 |
| 公约前520年前后 | **黑帆之灾** | 海外遗物、本土秘密研究和港口结界共同造成恶魔性扩散 | 第一件遗物来自何处、哪些机构隐瞒了事故 |
| 公约前480—450年 | **开门革命与析光流亡** | 长庭围绕魔法研究、知识开放和封潮令发生内战；流亡者建立析光城 | 革命首次流血由哪方造成，失踪典籍现在何处 |
| 公约前72—64年 | **第一次护约远征** | 人类诸邦攻占三河城，建立圣城护领与沿河堡领 | 朝圣队遇袭责任、最初动员中的神迹和各诸侯真实目的 |
| 公约前60—55年 | **第二次护约远征** | 新军与移民巩固护城领，战火扩展至北岸祖誓道和东部水道 | 它是援助远征者后裔，还是将临时占领变成永久殖民 |
| 公约前47年 | **芦原会战与卡赫兰收复三河** | 卡赫兰联盟击败护领主力，恢复部分圣区和地方公议会 | 其宽仁政策中个人信念与现实算计各占多少 |
| 公约前43—36年 | **第三次护约远征／海冠远征** | 海冠王与卡赫兰互有胜负，最终开放谈判与有限朝圣 | 后世骑士文学对两位统帅关系的美化程度 |
| 公约前22—18年 | **第四次护约远征** | 最后一支大型远征军未能夺城，财政崩溃迫使各方接受长期谈判 | 谁暗中资助远征，以及哪些修会拒绝停战 |
| 公约前1年 | **最后誓本议定** | 多轮战争、停战和修订形成最终公约文本 | 某些秘密附约是否真实存在 |
| 公约纪1年 | **三河公约纪元开始** | 三方交换誓本，驻军限制、朝圣、墓地和初衡台共管获得制度基础 | 后世是否故意把混乱的签约过程写成单一仪式 |
| 公约纪74—96年 | **北方旧盟重组与第一次大陆战争** | 多个兽人部族重建驿路；百泉封锁最终将人类、兽人和精灵卷入多战区战争 | 谁首先把局部关隘战争扩大为大陆动员 |
| 公约纪241—248年 | **云泽继承危机与远枝盟约** | 长庭放弃祖源宗主权，多数半身人诸邦加入精灵联盟 | 沿海王室是否真的策划吞并，哪些云泽家族两边下注 |
| 公约纪286—301年 | **第二次大陆战争与新共主时代** | 寒潮、封路、云泽转盟和长垣扩建引发全面动员；兽人新共主在战争中崛起 | 哪一方的预防性部署真正使战争无法避免 |
| 公约纪317年 | **深炉再鸣** | 数座静默铸城出现同步信号，荒原遗迹活动增加 | 晶格幸存者、深眠者或现代模仿者谁在发声 |
| 公约纪327年 | **逆潮之年／当前时代** | 三方秘密安全工程共同响应深炉信号，三河逆潮使停战秩序濒临崩溃 | 谁取走誓本印记，以及深炉信号是否具有明确意志 |

## 8. 编号战争与史诗感

“第一次”“第二次”主要是后世史家的分类。当事人更常按照圣地、旗号、统帅、灾害或战场命名。只有出现了性质相近的后续战争，早期事件才会被追称为“第一次”。

### 8.1 四次护约远征

| 编号 | 人类通称 | 其他常见称呼 | 历史后果 |
|---|---|---|---|
| 第一次 | 第一次护约远征 | 兽人“失渡之年”；三河“西旗陷城” | 三河城陷落，圣城护领和堡领体系建立，朝圣保护第一次变成领土统治 |
| 第二次 | 第二次护约远征 | 精灵“水道封锁期”；三河“新民入城” | 远征者由临时军队变成当地社会，后来的收复不再能简单驱逐所有后裔 |
| 第三次 | 海冠远征 | 兽人“复誓守城”；三河“海旗之围” | 卡赫兰与海冠王的战争进入传说，有限朝圣、赎俘和贸易谈判开始制度化 |
| 第四次 | 最后护约远征 | 三河“饥营之冬”；地精“坏账远征” | 远征财政与补给崩溃，军事修会分裂，最终公约谈判成为现实选择 |

四次远征不能只是四次规模递增的攻城战。它们分别改变**领土、人口、外交和制度**，因此玩家在遗迹、家族和法律中仍能看到不同后果。

### 8.2 第一次大陆战争：九旗战争

公约纪74年至96年间，连续旱灾使百泉走廊的泉权和三河上游粮价失控。人类边侯以保护商队为名修建关堡，北方旧盟要求恢复季路，精灵则担心双方工程改变东部水量。一次地方冲突经过征粮、报复和盟约连锁，最终扩展到百泉走廊、三河平原和针叶林河谷。

后世称其为**第一次大陆战争**，当时多称“九旗战争”。它没有统一善恶阵营：人类城市可能与兽人河谷部族共同反对边侯，精灵诸庭也曾分别支持交战双方。战争最终确立百栈城的武装中立、商路共同检查制度和三河公约的第一次大修订，却没有解决北方联盟继承问题。

### 8.3 第二次大陆战争：断路战争

公约纪286年至301年，持续寒潮迫使北方部族南移；人类扩建百泉堡链，精灵北境长垣封闭更多季节渡口，云泽转盟又使人类担心西南通道被切断。各方都把集结军队解释为预防措施，最终形成无法停止的安全困境。

兽人当代共主在战争中整合草原、河谷和边城军队；人类联盟第一次实行跨王国总动员；精灵同时在长垣、三河和南海维持三个战区；半身人情报网、矮人火器、析光结界和地精运输使战争具有前所未有的组织规模。中立史家称它为**第二次大陆战争**，民间更常叫“断路战争”。

公约纪301年的“百栈停战”冻结了主要战线，却没有形成真正和约。当前时代的共主、诸侯、长庭执政者和云泽议员中仍有大量参战者；今日军制、边界、难民社区、战争债务和技术管制都由这场战争塑造。

### 8.4 大事件的命名规则

后续增加历史事件时至少满足一项，才进入世界级年表：改变联盟构成、重画交通与疆界、创造跨国制度、造成持续数代的人口迁徙，或改变魔法和工程的使用方式。纯粹“死了很多人”不足以制造史诗感。

建议同时记录三个名称层次：**中立史学名、当事方名称、地方居民俗称**。这能让“第一次大陆战争”提供清晰索引，又不抹掉各方对战争原因的争论。

## 9. 史料如何互相冲突

| 史料 | 优势 | 固有盲点 |
|---|---|---|
| 精灵档案与活见证 | 时间跨度长、天象和水文记录连续 | 长庭掌握编目权；长寿见证人也会修饰记忆和维护家族立场 |
| 人类城市档案 | 税册、法庭、军令和私人书信数量巨大 | 王朝更替、火灾和语言变化造成断层；教会抄本可能改写地方文本 |
| 兽人口传与路线记忆 | 能保存迁徙、生态和关系网络，表演本身可互相校验 | 后世史家常误把象征语言当作逐字记录；共主会重编长歌 |
| 半身人情报档案 | 跨境、精细、擅长识别不同版本和伪造 | 保密制度使外人无法验证；情报机构也会制造可控泄密 |
| 地精账册与历表 | 日期、价格、路线和当事人高度具体 | 只记录可结算关系；商会可能隐去真正货物与出资者 |
| 遗址与魔力残响 | 不依赖后世文字，可揭露被删除的活动 | 残响会被施法者预期影响，器物无法独自解释行为意义 |

战役不需要让玩家收集所有材料后解锁“唯一真相”。更合适的做法是：证据可以推翻宣传中的简单版本，却仍允许玩家对动机、合法性和超自然解释作出判断。

## 10. 对首部游戏的实际约束

首部作品只需让玩家记住五个时间锚点：**古代初衡、开门革命、圣城远征、第二次大陆战争、逆潮危机**。其他年代通过英雄背景、遗迹和任务逐步出现。

- 开场字幕只使用“公约纪327年”，不解释完整历法。
- 三族战役对同一历史事件使用不同名称，但菜单编年史提供中立换算。
- 三河城是共同历史入口，不是所有主线都必须争夺的唯一地图。
- 神迹可以发生，但不能自动证明某一传统的全部教义；魔力现象、元素意志和集体信念都可能产生相似结果。
- 英雄可以信仰、怀疑、改宗或只遵守世俗公约，阵营身份不自动决定个人信念。

## 11. 明确保留的空白

1. 世界是否由有意志的存在创造，还是虚空分化的自然结果。
2. 精灵是否真是第一种智慧生命，以及晶格群、元素生命和未知古族的年代关系。
3. 初衡台的建造者、最初用途和地下完整规模。
4. 初约是一场真实会议、一次超自然启示、多次灾害经验的合并，还是后世共同神话。
5. 三种衡约传统是否指向同一种超越意志。
6. 当前太阳年、月份、闰日和月相制度的精确数值。
7. 深炉再鸣与当前战争之间是否存在直接因果关系。
