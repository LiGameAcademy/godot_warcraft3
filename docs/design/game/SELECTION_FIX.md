# 单位点选与选中环修复（2026-09-25）

## 已定位的问题

1. UnitSelector 原来只计算射线与脚底水平面的交点，身体和屋顶没有拾取体积。52 px 的单位脚底兜底又很宽，可能抢走附近建筑命中；建筑仅有 28 px 兜底。
2. `_hud_blocks_screen` 把屏幕底部 22% 整条屏蔽，与现代 HUD 的多个独立面板不匹配。面板之间明明可见的地图也无法点击。`_input` 阶段还可能读取到上一位置的 hovered Control。
3. 原来松键时才拾取和发出选中通知；移动目标在此期间可能走开。4 px 的拖动阈值容易把手抖当框选。
4. GameDirector 转发与 UnitSelector 自身 `_input` 同时启用，输入所有权依赖节点处理顺序。
5. SelectionRing 是固定高度的平面。关闭深度写入不等于关闭深度测试，render_priority 也不能让它越过不透明地形。原来的局部 Y 偏移和尺寸还会继承宿主缩放与倾斜。
6. 首版包围盒修复仍不正确：主城包围盒包含屋顶斜边外、建筑间隙等空白；只比较盒子入口深度，会抢走实际可见农民的点击。此外，以 `abs(determinant) < 1e-6` 判断不可逆变换会误拒绝正常的微小模型缩放（0.005 缩放的行列式为 1.25e-7），使农民身体拾取退化为脚底兜底。此前的普通大小 BoxMesh 用例未覆盖这两个问题。

## 本轮修改

- 包围盒仅作初筛，真正命中由模型三角形表面及距离决定；标准材质的透明纹理孔洞继续向后查询。正常的小缩放不再被误拒绝。无模型表面命中时保留脚底容错，没有改为无条件优先农民。
- 静态三角形和原始顶点数据按 Mesh 缓存；骨骼模型从当前骨骼姿态在 CPU 更新候选网格，结果每帧复用，避免悬停时反复从 GPU 读回网格。隐藏网格、选中环和粒子等不参与身体拾取。
- 包围盒缓存存在 Model 节点上，替换模型会自然失效，空模型不缓存。地图装配阶段预计算已有模型，查询不批量实例化选中组件。粒子、选中环和贴地网格不参与身体范围。
- 按下鼠标即选中；松开时保留按下命中的目标。8 px 内容许手抖，真正拖动仍执行己方框选及单位优先规则。重复选中相同集合不再重建 HUD。
- HUD 面板按实际可见矩形登记 world_input_blockers，移除粗条带；读取 hovered Control 时校验当前事件位置。
- MatchInputController 绑定后，UnitSelector 的独立 `_input` 停用；退役接收器继续停用以免抢新实例输入。独立场景可显式调用 `set_external_input(false)` 恢复。
- 选中/悬停/交互环作为不受地形深度遮挡的反馈显示；以世界单位保持水平和尺寸，只在可见时跟随宿主位置。这个方案会让环覆盖其他三维遮挡物，并非地形贴花；隐藏宿主仍隐藏环。

## 验证入口

- `tests/unit/selftest_unit_selection.tscn`：33 项检查，新增建筑空隙、实体遮挡、透明孔洞、0.005 模型缩放与真正零缩放；保留身体/屋顶命中、隐藏与离场过滤、即时反馈、移动目标、手抖、重复通知、HUD 间隙、模型替换、选中环变换、路由与框选规则。
- 现有 `selftest_match_input.tscn`、`selftest_selection_hud_module.tscn`、`selftest_module_bindings_game.tscn` 覆盖命令瞄准、HUD 和真实对局模块重绑定。
- `tests/media/selection_review.tscn`：真实 Echo Isles 对局，在 1920×1080 独立 SubViewport 中经 `push_input` 注入实际鼠标事件，检查主城上半部点选、一次通知及 HUD 点击区域；把真实农民移到真实坡地，在同一位置切换深度测试生成对照。测试不修改地图资产或用户对局。
- 同一真实场景测试加入独立 GPU 对照：临时给真实主城、农民材质输出不同的物体标记颜色，覆盖开局及主城周围 4 个重叠位置；恢复材质后比较 CPU 拾取结果。只比较完整 3×3 邻域同色的模型内部像素，避免抗锯齿边缘的亚像素歧义，并确保实际包含被旧包围盒抢走的农民像素。最终通过真实鼠标事件选中该农民，输出 `peasant_overlap_selected.png`。

截图写入 `tmp/selection-review/`。测试暂时冻结对局以固定画面，并关闭开场肖像预热；其点击计时只用于定位 CPU 回调开销，不是正常游戏端到端响应延迟或性能保证。首次 HUD 冷启动开销仍单独记录。

边界：这里修正单位与建筑模型之间的拾取，不是完整的 GPU picking 管线。仍未加入地形/其他场景物体的全局遮挡或战争迷雾；未知自定义 ShaderMaterial 按不透明表面处理，当前队色材质符合此规则；透明边缘的纹理过滤和抗锯齿不保证逐像素等价。模型缓存的初筛范围来自导入几何，极端超出原始范围的动画还需要专门的动态范围支持。

首版历史实测（Godot 4.6.3 / D3D12）：主城测试点距离脚底投影 64.1 px，经真实视口事件可在按下时命中。连续 20 次重复点击平均 CPU 回调约 1.82 ms；首次选中回调约 30.24 ms，其中 HUD/选中事件处理约 24.67 ms。这组结果没有覆盖主城与农民重叠，不能证明拾取正确。

重叠修复最终实测（同环境，`tmp/selection-review/cpu.log`）：711 个模型内部采样点与 GPU 渲染一致，0 个差异；其中 210 个农民像素会被旧包围盒错误遮挡。真实视口点击 `(1043.5, 447.5)` 选中农民，媒体测试 21 项通过；选择单测 33 项、输入路由 12 项、选择 HUD 6 项通过。跨 10 帧刷新姿态的农民拾取平均 3.33 ms（中间 GPU 网格回读方案约 16.52 ms，已替换）。重复主城点击平均 2.01 ms，首次选中回调约 29.89 ms，其中 HUD/选中事件约 24.55 ms。环境仍有证书/着色器缓存写入错误和退出时 ObjectDB 清理告警，最终运行无脚本解析/运行错误；采样数随开局动画姿态略有变化。

修改仅涉及选择器、新增拾取工具、输入路由的选择器所有权、HUD 场景的阻挡分组和共享选中环组件；保留同工作区并行的建造、科技、单位形态与命令面板改动。
