# 地形重构第二轮：处理策略与保底

> 历史阶段记录：单格保底现已扩展为连通区域保底；当前准入规则、构建职责与验收约定见 [RAMP_ARCHITECTURE.md](RAMP_ARCHITECTURE.md)。

局部形状与渲染处理分开：State.classify 描述层差，State.resolve 决定 NON_RAMP / SUPPORTED / INVALID / FALLBACK。模型覆盖作为上下文证据优先，不能只凭四角把候选认定为原版模型已支持。

范围为四角 0..3 层高和 16 坡旗组合、未传入邻域模型证据时：

|处理|原始输入|归并状态|
|---|---:|---:|
|非斜坡|256|34|
|已支持单层入口|36|3|
|平地残留旗/不完整旗|3588|368|
|完整标记的保底候选|216|30|

INVALID 是“不能独立形成完整斜坡”，并不表示地图损坏或用户操作违法。邻域匹配出原版模型后会进入 SUPPORTED；否则保持基础地形，不清除保存旗位。绝不把所有带单个坡旗的邻近崖壁都变成坡面。

保底：四角旗完整且没有原版模型覆盖的交叉坡形/多层坡形，通过现有地表三角化器生成带原地表纹理的单元；地面、直崖共享接缝计划，并移除该单元直崖，避免双重覆盖。该路径复用正常地面的材质和网格更新，不额外挂遮洞平面。地图层高/坡旗保持不变。

构建计划新增 routes/cells/fallback_tiles/ground_tiles，保留 source entrances 与渲染 ground_tiles 的区别。缓存生命周期仍为单次 MapBuildContext。所有单元有一个统计分类，候选记录包含原因与 canonical key。

测试：4096 组合覆盖策略、旋转镜像不变性；selftest_ramp_fallback 使用 D3D12 对 [2,3,3,2] 和 [2,4,3,2] 检查实际地面、非退化三角形、相邻直崖周界高度、无重复直崖、擦除后恢复基础地形。111 continued、222 回归通过。截图 tmp/ramp-fallback.png；分类统计 tmp/ramp-state-routes.json。

限制：这是首批保底，不是任意邻域的无缝证明；不完整旗仍保守显示原始地形。未新增游戏通行规则，不应根据保底外观自动认定可以行走；完整的邻域模型冲突、路径/拾取统一验证、自动生成所有候选的几何审计仍需后续迭代。
