# 地形重构第一轮：分类与构建计划

基线提交 4161ccd（222 接缝修复）。

新增 Wc3RampCellState：平地、直崖、单层坡形候选、多层坡形候选。以 BL/BR/TL/TR 四角为输入，状态键消除绝对层高以及 D4 旋转/镜像差异。4096 输入覆盖四角层高 0..3 和 16 坡旗组合，归并 435 类；不代表原版模型类型数，也不涵盖所有邻域组合。

新增 RampSurfacePlan，集中入口、挖洞、接缝高度及未匹配候选列表。MapBuildContext 按一次构建缓存，直崖/坡体/地面接入同一结果，避免各层重复计算。保留已有几何输出。unhandled 提供 tile、canonical state、kind，可作为下一轮分类资产表及保底生成的输入。

尚未实现：邻接边/交汇角完整枚举、程序化保底网格、任意输入无缝保证。不能将候选状态或当前存在直崖模型视为已完整支持。

独立完成编辑器建筑吸附：UnitPlacementRules.snap_editor_position 根据脚印尺寸和寻路格原点吸附建筑中心，保证脚印最小角在格线上。普通单位原坐标返回。预览/放置/拖动同规则，混合选择时各建筑按自身脚印吸附；原有地图加载不改写。测试包含实际放置、拖动、撤销重做与普通单位自由坐标。未改变游戏建造选址算法。
