# 编辑器验收样例

`acceptance.wc3map.json` 是 64×64 洛丹伦夏季地图，包含泥土与草地纹理、一块升高地形，以及四类原版对象：农民 hpea、城镇大厅 htow、夏季树 LTlt、岩石 LRrk。农民生命值设为 75%。配套 `acceptance-preview.png` 是保存并重新读取此地图后生成的实际 D3D12 预览。

## 打开与复验

1. 在 Godot 中运行 `editor/scenes/editor_main.tscn`（F6）。
2. 选择“文件 → 打开 → 打开编辑器地图文件…”，选取此目录下的 `acceptance.wc3map.json`。
3. 检查四类对象、草地区域和高低地形；双击农民检查生命值 75%。
4. 移动、旋转任一对象，撤销后重做；使用“另存为”写入自己的测试路径。
5. 重新打开另存的地图，进入“文件 → 测试地图”，检查地形及四类对象；关闭预览后继续编辑。
6. “查看 → 地图资源检查”应不报告上述四种对象缺少定义或模型路径。

## 生成证据与边界

`tests/integration/selftest_editor_acceptance_sample.tscn` 使用当前面板信号、屏幕坐标笔刷入口和单位属性窗口生成地图；验证保存重开、四个模型实例存在、占位模型计数为零及属性保留。D3D12 测试 PASS，日志为 `logs/editor-acceptance-sample.log`。预览截图已视觉检查；这不替代上述人工复验步骤，也不证明所有原版资产和游戏系统均兼容。

运行该场景会重新生成本目录的地图与截图，修改样例前请另存。
